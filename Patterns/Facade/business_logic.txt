User Story: As a customer, I want to be able to complete my purchase checkout seamlessly through a secure, coordinated payment settlement process.

When processing customer checkout payments, the checkout system must coordinate multiple independent subsystems in a strict business sequence:

1. IFraudService - Evaluates transaction risk score using customer email, card details, and amount.
   - If risk validation fails, the transaction is immediately aborted (card is never charged, ledger is never recorded), and a failure alert is dispatched.

2. IPaymentGateway - Interacts with card acquirer networks to authorize and capture funds.
   - If gateway declines authorization (e.g., insufficient funds, expired card), the transaction stops, ledger is not recorded, and a failure alert is dispatched.

3. ILedgerService - Posts balanced double-entry accounting records for successful payments and generates an immutable ledger reference code.

4. INotificationService - Dispatches customer receipts and real-time alerts:
   - On success: sends confirmation receipt with order ID, amount, and authorization code.
   - On failure: sends decline notification with failure reason.

IPaymentSettlementFacade coordinates this multi-service pipeline, shielding checkout callers from the complexity of orchestrating and error-handling across all 4 subsystems.
